# Dead-code cleanup — 2026-11-04

Follows the cleanup order in `REPORT-2026-11-04.md`. The audit itself was read-only;
this file records the changes made afterwards.

## Decision taken

Both retired features were never mounted: a `return-requests` route and an
`/api/devices/eod-time` route have never existed in `apps/api/src` (confirmed with
`git log -S`). Building them would be feature work, so the cleanup **retires** them
rather than adding routes.

The EOD time control was also only half-wired: the BullMQ worker runs at a fixed
`0 0 * * *`, while the removed endpoint only changed an in-process variable. The UI
now schedules by date and states that the update applies at the EOD run, instead of
offering a time that the worker would ignore.

## Deliberately left in place

- **`KioskReturnRequest` model and migration.** No code path can write it now, but
  dropping it requires a new destructive migration. No such migration was added.
- **`auth.controller.ts` `crypto` import and `token.ts` `SignOptions` import.** The
  write guard refuses to rewrite those files because it detects credential-shaped
  literals (`auth.controller.ts:378`, `token.ts:47`). These are the only two unused
  imports left; TypeScript still flags them. They need a manual edit or a guard
  decision, not a bypass.
- **`DecisionDialog` reject branch.** It is unreachable (the only call site passes
  `"approve"`, and the reject routes were removed), but deleting it means changing
  the component API and the stale `scripts/decision-ui-check.tsx`, which still
  asserts reject endpoints. Left for a focused UI/test cleanup.
- **`fetchMembers`** in `backend-api.ts`. It calls the unimplemented
  `GET /api/members` (known 404) but is still imported by `RolesScreen`; it is live
  code with a missing backend, not an unused symbol.
- **`EOD_PRICE_RUN_TIME`.** It remains an undocumented override for the reported
  run time. The worker still runs at midnight; the default is `00:00`, so the local
  configuration is consistent.
- **`ioredis` / `@types/ioredis`.** Lower-confidence candidates: nothing imports
  them directly, but BullMQ lists `ioredis` as an optional peer, so they were not
  removed.
- **Vercel bundles.** `apps/api/api/index.mjs` is a stale, gitignored artifact
  from 2026-10-07; the current build writes `<repo>/api/index.mjs`, and nothing
  references the old folder. The root bundle was regenerated on 2026-11-04
  (483,370 bytes, 82 first-party modules) and no longer contains the retired
  routes. The old `apps/api/api/` folder was deleted on 2026-11-04.
